Mailboxes

Connect an Azure / Microsoft 365 (Outlook) or Gmail mailbox to summarize.

The app keeps an encrypted Microsoft token only for the period you choose, then deletes it. Reconnect to extend.

Add a shared mailbox

You'll sign in with your own Microsoft 365 account, which needs Full Access to this mailbox (and Send As or Send on Behalf to forward invoices from it). Ask your Microsoft 365 admin if you don't have it.

Add a mailbox with API keys

Uses an Azure app registration in your tenant with Microsoft Graph application permissions Mail.Read and Mail.Send, admin-consented. The keys are stored encrypted for the access period above and never shown again.
